<h1 align="center">Kite</h1>

<p align="center">Ayudante ligero para League of Legends: runas y builds de OP.GG al instante, sin anuncios.</p>

## Instalar

1. Descarga **[Kite.exe](https://github.com/TeddyDevDev/Kite/releases/latest/download/Kite.exe)** (última versión).
2. Ponlo en cualquier carpeta y ábrelo con doble clic.
3. Abre League of Legends: Kite se conecta solo.

> Si Windows avisa con **"Windows protegió su PC"**, pulsa **Más información → Ejecutar de todas formas** (pasa con cualquier programa sin firma digital).

No hace falta instalar nada más.
